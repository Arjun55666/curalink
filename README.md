# CuraLink

A healthcare management system built using React, Node.js, and Supabase.

## Features
- Admin Login (JWT Auth)
- Patients Management
- Doctors Management
- Appointment Booking
- Dashboard Overview

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: Supabase

## Setup

### Backend
cd backend
npm install
npm startgi

### Frontend
cd client
npm install
npm run dev
